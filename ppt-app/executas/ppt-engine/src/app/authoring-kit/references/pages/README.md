# Pages（页面组合参考）

- `FormalCover.tsx`：正式汇报场景的封面层级和演示身份元数据参考。
- `ChartWithNarrative.tsx`：一张主图表需要配合 2–4 条解释和一个结论时参考。
- `ImageNarrative.tsx`：一张主图需要配合视觉解读和事实约束说明时参考。
- `KpiSummary.tsx`：少量指标、状态和总结需要同页呈现时参考。

先判断页面角色和信息结构，再选择参考。正式封面不是所有 Deck 的第一页；不要为了复用示例而强行改变页面叙事。Preview 中的标题、日期、身份、指标和结论都只是示意内容，不能作为当前 Workspace 的事实。
